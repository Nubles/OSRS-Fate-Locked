# Quest required-item sources — 5 September 2026

Retrieved all 210 canonical quest/miniquest pages through the OSRS Wiki MediaWiki API. `data/sources/quest-operational-items.json` records each actual page, revision ID and timestamp, raw required-item field, and derived confirmation clauses. Page titles come from the existing canonical quest source registry, including Recipe for Disaster subquests. Exact source URLs are `https://oldschool.runescape.wiki/w/index.php?title=PAGE&oldid=REVISION`, with PAGE URL encoded.

The parser reads the `items` field of Quest details or Miniquest details and never the separate `recommended` field. An embedded Recommended section is excluded, as are wholly optional entries. Nested lists remain attached to their parents so “item OR a gathering route” does not become two mandatory requirements. Quantities, unnoted restrictions, multiple trips, and quest-obtainable conditions are retained. Inline recommendations remain source context and are explicitly optional in the confirmation label. No acquisition skill is inferred from possessing an item.

This is **required-item field coverage**, not a semantic proof of every walkthrough action. A source listing no starting items does not imply no quest-provided tool or restricted method. The separate operational-method checks remain necessary. Unsupported templates, missing pages and absent fields produce UNKNOWN instead of a generic confirm-to-pass condition. Future source revisions require review; the scheduled freshness monitor includes these 210 pages.

Two absent item fields were reviewed against their complete current walkthroughs: Children of the Sun requires no carried supplies; The Restless Ghost provides the ghostspeak amulet and skull during the quest, requires legally wearing the amulet, and permits avoiding the skeleton. Their explicit review notes distinguish these decisions from automatic extraction. An explicitly empty item field means the page lists no starting supplies; it is not evidence that every quest action is permitted.

The development-only extraction command requires explicit input and output paths and writes a review draft. It does not fetch or silently refresh accepted semantics. Tests compare every captured item field with its stored clauses, ensure canonical coverage, and verify alternatives, recommendations, unsupported markup and provided-item behavior. The two walkthrough decisions are the only explicit overrides.
